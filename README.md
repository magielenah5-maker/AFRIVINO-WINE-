# AFRIVINO Wine Advertising Website

A responsive, animated promotional website for AFRIVINO.

## Files
- `index.html` — website structure and page content
- `style.css` — responsive layout, colours, typography and animations
- `script.js` — mobile navigation, age confirmation, scroll reveals and contact email action

## Preview locally
Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and the remote Unsplash photographs.

## Publish with GitHub Pages
1. Upload all three files (`index.html`, `style.css`, `script.js`) to the root of your AFRIVINO repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The URL will usually be `https://magielenah5-maker.github.io/AFRIVINO-/`.

## Before launch
- Replace `hello@afrivino.com` in `index.html` and `script.js` with the business's real email address.
- Replace the sample wine descriptions and stock photographs with approved AFRIVINO product details and images.
- Replace the stylised A monogram with the official AFRIVINO logo when supplied.
- Confirm the age-gate wording meets applicable local laws. The site is a promotional template and does not process orders or payments.
